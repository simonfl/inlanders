# F34a — public identity and first reference palette

Les Habitants — A home for generations. The tagline describes the settlers' hopes, not inheritance or any generational mechanic. Menu, HUD and runtime window title share a small public identity class. Project, assembly, namespaces, save names and developer tooling retain Inlanders.

## First scene reference

Art direction: a fictional rural St. Lawrence settlement around **1670–1680**. This is a working reference window, not a claim that every existing asset is accurate. Keep English functional controls and use French chapter/place names with an English explanation. Story text can evoke an established inhabited region and hopes for a lasting home; no family progression system follows from it.

| Element | Direction for the first scene | Status |
| --- | --- | --- |
| Dwelling | Modest rectangular timber house, simple gable, small openings, visible chimney; subdued timber/earth palette. | Stylized selection from the varied St. Lawrence evidence, not a reconstruction of a named house. |
| Worked land | Kitchen garden near the dwelling; longer cereal plots beyond, paths between practical work areas. | Composition choice. Exact crop species/yields remain current game abstractions. |
| Food/work structure | Small utilitarian timber shelter and a legible masonry oven; store actual produce where workers use it. | Artistic interpretation. Research a specific milling mechanism before adding one. |
| River landing | Modest timber access to the shore with useful loading space. | Provisional visual design; current dock/boat rules remain. |
| People and tools | Restrained linen/earth clothing palette, readable hand tools and carried baskets at ordinary zoom. | Provisional silhouette/color brief; specific cuts/headwear need dated object references before an authenticity claim. |
| Materials | Weathered wood, pale mortar/plaster accents, rough stone, muted roofs; distinguish jobs through form and activity. | Artistic palette rather than historical color reconstruction. |

The museum describes substantial variation across regions and periods, with timber prominent in early St. Lawrence construction. Its dated examples include early farm buildings and a dwelling used around 1670–1680; these support choosing a local/time-bounded reference rather than copying later postcard architecture. [Canadian Museum of History: Vernacular Architecture](https://www.historymuseum.ca/virtual-museum-of-new-france/daily-life/vernacular-architecture-in-new-france/).

Cultivated food and local fish/game/plant use provide the broad food context; current recipes remain gameplay abstractions. [Canadian Museum of History: Foodways](https://www.historymuseum.ca/virtual-museum-of-new-france/daily-life/foodways/).

First visual acceptance belongs to the inhabited F33b/F34b scene, with opposite cameras, actual work and an audio audition. This reference sheet is not visual or historical acceptance of the current catalogue. See [theme scope](LES_HABITANTS.md).
